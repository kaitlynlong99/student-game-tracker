# Student Grade Tracker
A Java console-based application that allows users to manage and track student assignment grades. 
The system organizes grade data using a Binary Search Tree and stores records using a HashMap for efficient access.

## Technologies Used
- Java
- Data structures (Binary Search Tree, HashMap)

## Features
- Add students to the system
- Remove students from the system
- Add assignment grades
- Update assignment grades
- View individual student grades
- Display top-performing students
- View sorted grades
- Console-based interactive menu

## How It Works
1. The program runs in the consol and displays a menu of available actions.
2. Users can add or remove students from the system.
3. Assignment grades can be added or updated for each student.
4. Student records are stored using a HashMap.
5. Grade data is organized and sorted using a Binary Search Tree.
6. The system can display student grades and identify top-performing students.

## Project Purpose
This project was created to practice implementing core data structures in Java and applying them to a practical problem involving student grade management and data organization.
